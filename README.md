# 🌌 Exoplanet Discovery: The Hunt for Earth 2.0
An end-to-end data science project bridging **Astrophysics** and **Data Analytics**.

## 🚀 Project Overview
As a final-year Astronomy student at **Istanbul University** and a Data Analysis trainee at **Marmara University**, I developed this pipeline to identify potential habitable candidates among 9,500+ celestial objects using NASA Kepler Mission data.

## 🛠️ Technical Workflow
* **SQL Wrangling:** Initial extraction of 9,500+ KOIs (Kepler Objects of Interest) using custom SQL queries to create a high-potential subset (`data_extraction.sql`).
* **Data Cleaning:** Used **Python (Pandas)** to handle unit calibration (Kelvin, Earth Radii) and normalize NASA's Confidence Score.
* **Exploratory Data Analysis (EDA):** Visualized the 'Habitable Zone' using **Seaborn** and **Matplotlib**, mapping candidates against Earth-like physical constraints.
* **Key Finding:** Identified **Kepler-296 d** as a prime "Earth 2.0" candidate with an ideal equilibrium temperature of 297 K (24°C).
